# 칩메이트 MCT NC 시뮬레이터

설치 없이 브라우저에서 실행하는 한국어 3축 밀링 NC 시뮬레이터 프로토타입입니다. 주 화면은 코드 입력, 소재·공구·바이스 설정, 실행, 입체 소재 결과 검토로 구성했습니다. 앞서 만든 가공조건 학습 화면은 보조 기능으로 아래쪽에 배치했습니다.

기본 사용 순서는 `제어기 프로파일 → 소재·공구·치구 설정 → NC 코드 분석 → 블록 실행 → 경로·결과 확인`입니다. 왼쪽 고정 메뉴와 빠른 실행 버튼에서 예제 불러오기, 코드 분석, 시뮬레이션을 바로 시작할 수 있습니다.

## 실행

`index.html`을 Chrome, Edge 등 최신 브라우저에서 엽니다.

## 구현 기능

- 소재, 공구, 가공 유형 선택
- 절삭속도, 날당 이송량, 축·반경 절입량 조절
- 회전수, 테이블 이송속도, 재료 제거율, 주축 동력 계산
- 소재별 학습 기준 조건 추천
- 가상 절삭 애니메이션, 실험 과제, 공식 설명과 단계별 힌트
- 조건 변경과 장비 한계에 따라 달라지는 개인화 피드백
- NC 코드 편집, 블록 분석, 한 블록 실행 및 전체 재생
- G0/G1 직선 경로, G2/G3의 XY 평면 I/J 또는 R 원호, G90/G91, G20/G21 해석
- G73/G81/G82/G83 기본 드릴 사이클, G43/G49 단일 H 길이 보정, M3/M4/M5 주축, M6 공구 교환, M7/M8/M9 냉각수, M00/M01 정지, M02/M30 종료 해석
- 0.5 mm 샘플 간격의 엔드밀 스윕 기반 2.5D 높이맵 소재 제거와 입체 표시
- 급속 공구-소재 간섭, 공구/홀더-잔삭 소재 간섭, 간이 바이스 간섭, G54 원점 기준 입력한 축 이동한계 검사
- 소재·공구·바이스 치수와 G54 기계 원점/기계 이동한계 설정
- NC 파일 열기, 블록별 실행, 예상 이동 시간, 제거 체적 표시
- 가공조건 변화에 따른 NC 경로 시간 비교와 표면 품질 경향 피드백
- NC 코드 줄별 G/M 코드 해설, 좌표 주소 확인, 기초 위험 알림 및 코드 퀴즈
- 공작물 고정·공구·G54·공중 운전 셋업 체크리스트
- 채터링·원점 오설정·과다 이송 불량 진단 학습 사례
- 단일 패스와 황삭/정삭 분할 공정 계획의 단순 모델 비교
- 위 학습 모듈에 NC 분석/실행 상태와 현재 공구·소재 조건을 공유
- 학습 모듈별 확인 문제와 브라우저 저장소 기반 완료 진도 표시
- 간이 모델 위험 후보와 기계 전용 검증 제외 항목을 결과 옆에서 구분 표시

## NC 코드와 가공조건/미리보기 연동

NC 코드를 분석하면 계획 절삭 블록에서 `S`, `F`, `T`와 현재 공구 직경/날 수를 읽어 조건 패널에 전달합니다. 프로그램 실행 중에는 블록마다 회전수, 이송속도, 최대 Z 절삭 깊이를 갱신합니다. 소재 제거 높이맵으로 계산한 제거 체적과 절삭 시간에서 재료 제거율을 구하고, 소재별 비절삭저항으로 동력을 근사합니다. 소재 선택은 동력 계산에 반영됩니다.

하단 학습 모듈도 동일한 `mct:nc-link` 이벤트를 구독합니다. 코드 해설은 편집 중 프로그램을 읽고, 요약·조건 비교·공정 비교는 NC 분석/실행 시 전달된 F/S/T, 절삭시간, 제거 체적, 경고를 사용합니다. 소재·공구 선택은 기존 가공조건 패널 및 NC 설정을 통해 공유됩니다. NC 코드를 수정하면 이전 경로 결과는 학습 모듈에서 초기화됩니다.

`Vc`와 `fz` 슬라이더는 각각 G코드의 `S`, `F`에서 역산한 값으로 표시되고, `ap`는 프로그램의 최대 Z 깊이를 참고값으로 표시합니다. `ae`는 단일 NC 주소값이 아니므로 공구 경로와 높이맵에서 계산하며, 화면에 G코드에서 직접 읽은 값처럼 표시하지 않습니다. NC 코드가 연결되면 수동 조건 슬라이더는 잠기고, 미리보기의 실행 버튼은 NC 프로그램 재생/일시 정지에 연결됩니다. 코드를 수정하면 조건 화면은 수동 모드로 돌아가며, 다시 분석하면 연동을 복구합니다.

## 계산 및 한계

코치의 추천과 피드백은 시제품에 포함된 재질별 기준값과 조건 규칙으로 동작합니다. 외부 생성형 AI 모델이나 실제 장비 연결은 아직 설정되어 있지 않습니다. 절삭 동력은 비절삭저항 기반의 교육용 근사치이며, 절삭력·진동·표면 거칠기·공구 수명을 실측 수준으로 예측하지 않습니다.

코치의 오류 원인 설명, 단계별 힌트, 조건 피드백, NC 코드 맞춤 퀴즈는 입력 코드와 수치에 대한 로컬 규칙·계산식으로 만들어집니다. 이를 생성형 AI가 생성한 답변으로 표시하지 않습니다. 모듈 완료와 확인 문제 정답 상태는 해당 브라우저의 `localStorage`에 저장됩니다.

## 검증 범위와 주의점

현재 NC 엔진은 특정 MCT의 검증기나 VERICUT 대체물이 아닙니다. RS274/NGC 계열의 제한된 3축 공통 코드만 다루며, 선택한 제어기 프로파일도 M코드 옵션 의미를 완전히 바꾸지는 않습니다. 코드 의미가 지원되지 않거나 기하에 영향을 주는 미지원 코드가 있으면 그 블록에서 실행을 막습니다.

소재 모델은 기본 0.5 mm XY 셀의 높이맵이며, 큰 소재는 브라우저 처리량에 맞춰 셀 크기를 키웁니다. 평엔드밀의 이상적인 수직 절삭은 볼륨과 포켓 형상으로 나타나지만, 공구 런아웃·절삭 변형·스톡 소재 허용차·칩 재절삭·부품 내부 언더컷 등 실제 물리는 계산하지 않습니다. 화면의 빨간 표시와 경고는 이 간이 모델에서 발견한 위험 후보이며 실제 충돌 확정 판정이 아닙니다. 바이스는 프로그램에 포함된 단순 양쪽 죠 형상이며, 사용자가 실제 치구 CAD를 불러오는 기능은 아직 없습니다. 기계 검사는 입력된 G54 원점, 축 최대 이동량과 단순 공구/홀더 형상 기준입니다. 완전한 기계 충돌 검사는 기계별 CAD/키네마틱스, 실제 툴 테이블·워크 오프셋, 포스트/제어기 버전으로 별도 검증해야 합니다.

현재 지원하는 기본 코드는 `G0/G1/G2/G3`, `G17`, `G20/G21`, `G40`, `G43/G49` 단일 H 오프셋, `G54`, `G73/G80/G81/G82/G83`, `G90/G91`, `G94`, `G98/G99`, `M0/M1/M2/M3/M4/M5/M6/M7/M8/M9/M30`, `F/S/T`, 주석과 `%`입니다. G41/G42, G53/G28, 설정되지 않은 G55-G59, 파라미터·매크로·서브프로그램, 회전축은 검증을 중단합니다.

기본 관계식은 `n = (Vc × 1000) / (πD)`, `vf = fz × n × z`, `Q = ap × ae × vf / 1000`입니다. M코드는 주축·냉각수·공구교환·정지·프로그램 끝 상태를 제어합니다. 자세한 기준 자료와 제어기별 차이는 [G/M 코드 조사 노트](docs/gcode-support.md)를 참고하세요.
