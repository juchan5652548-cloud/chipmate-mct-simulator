CONNECTED PRACTICE

가공 학습 모듈

현재 NC 코드와 공구·소재 조건을 바탕으로 실험, 해석, 셋업, 진단, 공정 비교를 연습합니다.

NC 코드 대기
01 · 조건 영향 실험

이송 조건 바꿔보기

현재 NC의 F값 또는 수동 조건을 기준으로 이송 변화의 시간·표면 품질 경향을 비교합니다.

현재 조건을 읽으면 비교 결과가 표시됩니다.
모델 가정: 동일 공구 경로·절삭 길이에서 시간은 F에 반비례. 표면 품질은 이송만 반영한 교육용 경향 지표이며 실제 Ra 예측값이 아닙니다.
02 · NC 코드 읽기 훈련

코드와 동작 연결

편집기의 현재 프로그램을 줄별로 읽습니다. 분석된 현재 블록과 위험 알림을 함께 보여줍니다.

코드 해석을 누르면 지원 코드의 의미를 표시합니다.
03 · MCT 셋업 순서

가공 전 확인

실습 전에 셋업 항목을 체크하고, 빠진 절차를 확인합니다.

체크한 항목을 기준으로 셋업 준비도를 안내합니다.
04 · 불량 원인 탐정

가공 흔적 진단

측벽에 주기적인 물결 자국이 있고, 절삭 중 떨림 소리가 들립니다. 우선 의심할 원인은?

조건을 고르고 진단을 확인하세요.
05 · 공정 계획 비교

가공 순서 선택

동일 형상을 황삭·정삭으로 나눌지, 단일 패스로 가공할지 학습용 모델로 비교합니다.

NC 실행 결과가 있으면 실제 제거 체적을 우선 사용합니다.
시간은 NC 경로와 수동 조건을 단순화한 추정치이며 공구교환·가감속·비절삭시간은 시나리오 가정으로 계산합니다.
